🎣 Phishing

Phishing is a scam where an attacker pretends to be a trusted person or organization to trick you into giving information.

🚩 Red Flags

  • Urgent requests for immediate action
  • Suspicious links
  • Requests for passwords or OTPs
  • Unexpected attachments
  • Fear or pressure tactics

📩 Example

You receive an unexpected message saying your account needs immediate verification and asking you to click a link.

✅ Safe Action

Don't click the suspicious link. Open the organization's official website or app yourself and verify the message.

📱 Smishing

Smishing is phishing carried out through SMS or text messages.

🚩 Red Flags

  • Unexpected text messages
  • Suspicious links
  • Urgent requests
  • Requests for personal information

📩 Example

A text message claims that a delivery problem requires you to click a link immediately.

✅ Safe Action

Don't open the link. Check the delivery through the company's official website or app.

📞 Vishing

Vishing is phishing performed through phone or voice calls.

🚩 Red Flags

  • Caller creates urgency or fear
  • Requests passwords or OTPs
  • Caller claims to be an official
  • Requests money or sensitive information

📞 Example

Someone calls claiming to be from a bank and asks for an OTP to "secure" your account.

✅ Safe Action

Don't share OTPs or passwords. End the call and contact the organization using an official number.

💬 WhatsApp Scams

WhatsApp scams use messages, fake offers, impersonation and suspicious links to trick users.

🚩 Red Flags

  • Unknown contacts
  • Unexpected prize or job offers
  • Requests for money
  • Suspicious links

📩 Example

A message claims you have won a prize and asks you to click a link and provide personal information.

✅ Safe Action

Don't click the link or send money. Verify the offer through an official source.

🔗 Fake Links

Fake links can lead to fraudulent websites designed to steal information or deliver harmful content.

🚩 Red Flags

  • Misspelled domain names
  • Unexpected URLs
  • Unusual domains
  • Shortened links from unknown sources

📩 Example

A message contains a link that looks similar to a trusted website but uses a different domain.

✅ Safe Action

Don't rely only on the appearance of a link. Visit the organization's official website directly.

🦠 Malware

Malware is malicious software designed to perform harmful or unauthorized actions.

🚩 Red Flags

  • Unexpected software downloads
  • Suspicious attachments
  • Unknown applications
  • Unexpected security warnings

📩 Example

An unexpected email attachment asks you to download and open an unknown file.

✅ Safe Action

Don't open unexpected attachments. Use trusted software and keep your device updated.

🔒 Ransomware

Ransomware is malicious software that can prevent access to files or systems.

🚩 Red Flags

  • Unexpected file access problems
  • Unknown software activity
  • Suspicious attachments or downloads
  • Unexpected payment demands

📩 Example

A malicious file is opened and later the user discovers that important files are no longer accessible.

✅ Safe Action

Keep reliable backups, update software, and avoid suspicious downloads and attachments.

🔑 Password Security

Strong password practices help protect online accounts from unauthorized access.

🚩 Red Flags

  • Using the same password everywhere
  • Sharing passwords with others
  • Using easily guessed information
  • Writing passwords where others can access them

📩 Example

A user uses the same password for email, social media and other important accounts.

✅ Safe Action

Use strong, unique passwords for important accounts and consider using a reputable password manager.

🛡️ Multi-Factor Authentication

MFA adds an additional verification step beyond a password.

🚩 Red Flags

  • Unexpected MFA approval requests
  • Login alerts you don't recognize
  • Requests to share verification codes

📩 Example

You receive an unexpected login approval request even though you are not trying to sign in.

✅ Safe Action

Don't approve unexpected requests or share verification codes. Change your password and review account security if needed.

🚨 Reporting Scams

Reporting suspicious activity can help protect you and others from scams.

🚩 Red Flags

  • Suspicious messages or calls
  • Fake websites
  • Unexpected requests for sensitive information
  • Impersonation attempts

📩 Example

You receive a suspicious message pretending to be from a trusted organization.

✅ Safe Action

Don't interact with the scam. Save relevant evidence and report it through the appropriate platform or organization.
